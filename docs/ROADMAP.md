# Roadmapa

## V1

Sesje, konta, transakcje i transfery, kategorie/reguły, budżety, dashboard, analityka, generyczny import CSV, symulator i ustawienia motywu.

## V2

Zweryfikowane adaptery bankowe (w tym iPKO po próbce), edycja transferu jako całości, eksport danych, cele oszczędnościowe, pełniejszy OpenAPI, lazy-loading tras i rozszerzone testy integracyjne/E2E.

## V3

Obsługa wielu walut z tabelą kursów, transakcje cykliczne, gospodarstwa wieloosobowe i bezpieczne kopie danych.

Znane ograniczenia V1: tylko PLN, brak odzyskiwania hasła i MFA, generyczne nagłówki CSV, brak odsetek w symulatorze, saldo wyliczane w czasie odczytu oraz brak wdrożenia produkcyjnego w tym repozytorium.
